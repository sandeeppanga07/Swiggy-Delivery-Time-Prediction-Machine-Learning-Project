# Swiggy-Delivery-Time-Prediction-Machine-Learning-Project
End-to-end Swiggy Delivery Time Prediction using Machine Learning and XGBoost. Built with Python, Scikit-learn, and Streamlit to estimate food delivery time using rider, traffic, weather, location, and order-related features. Achieved an R² score of 0.8247 with an MAE of 3.13 minutes.
